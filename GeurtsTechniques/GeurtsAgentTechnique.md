## Purpose and ownership

This technique owns the Codex guide templates for legacy selected-folder installation and portable root onboarding. AGENTS.md selects it when installing, validating or explaining a Codex guide. The documentation startup authority is `AGENTS.md`; it selects specialist owners directly. The current templates below route directly to AGENTS.md. Historical payloads retain their exact bytes under distinct LEGACY markers for safe recognition of existing guides. God installs the portable root template during a confirmed schema-4 Commandments installation or Update. Compatible Angels releases retain the separate selected-folder and portable-root actions; no guide changes on startup.

The installer creates `AGENTS.md`, the filename Codex automatically discovers in the project instruction chain. Do not edit Codex configuration automatically or claim that any location affects every Codex task.

The legacy native-entry manager must not change Codex guides. The separate selected-folder installer may still replace only the guide explicitly chosen by the user. Existing user guides elsewhere remain user-owned. Old root guides can be replaced at their selected location with this installer; old guides are not silently removed.

The package-root AGENTS.md is the documentation authority, never an installable project-guide template. Do not keep a standalone project-guide AGENTS.md template in the documentation package.
