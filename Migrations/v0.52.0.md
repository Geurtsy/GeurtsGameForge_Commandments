# Steam preparation adoption

**Version:** 0.52.0
**Required package path:** `Migrations/v0.52.0.md`

This release follows the Stage 1 policy in v0.51.0 with published local preparation. Use the current Catalogue for exact immutable installation sources and the owning release's capability and validation records. The delivery cohort introduces God 0.37.0, independent BigBang 0.6.0 and optional Steam 0.1.0. It targets Windows x64 with Unity 6000.6.3f1 and the tested Mono profile. Steam Deck, Proton and other operating systems remain outside scope.

## Manual adoption

1. Preserve any managed local documentation edits before choosing God's separate confirmed Commandments Update. Content updates retain schema 3.0.0 and the existing four targets; they do not install bricks or change scenes.
2. Existing God users manually update God first through the current Catalogue. Keep licensed Odin Inspector and Quantum Console installed. Existing God does not require a BigBang reinstall, downgrade or another initial installation.
3. Install the optional Steam brick only when wanted. For the tested wrapper profile, use the owner's explicit pinned Steamworks.NET acquisition/check route or Unity Package Manager with the exact source recorded by the release. The wrapper belongs in the consuming project manifest and is not bundled into a Geurts package.
4. For a fresh BigBang installation, explicitly acquire and check the wrapper and licensed prerequisites before initial Install God. BigBang still opens and explains missing prerequisites independently. Get Latest Git Source, Install God and Open God remain separate actions.
5. Open Steam's Configuration, review the local defaults and explicitly save them when appropriate. Keep native activation off for ordinary local development. Use the owner's local inspection and build checks; they require no game AppID, Steam login, store page, depot or release pipeline.

## What the preparation evidence establishes

The owning releases record graphics-backed Editor tests, independent BigBang compilation, exact wrapper boundary checks, actual standalone/embedded normal/narrow UI interactions and native-free Windows Mono player observations. The optional peer fixture includes Diagnostics, Settings, Scene Loading and UI Foundations without adding mandatory peer dependencies. God's platform contracts remain vendor-neutral; runtime hosts remain owned by retained SCN_BigBang.

This is preparation acceptance for the recorded Windows environment. Light host skin, high DPI and physical-device input remain unverified. Native initialization, real identity/callback delivery, cleanup in a real Steam context and Steam-launched overlay rendering remain a separate incomplete milestone. IL2CPP/AOT is not certified by Mono evidence. Customer distribution, SteamPipe and the Steam release pipeline remain deferred.

The published releases and this guide do not update the live project, wrapper, installed packages, local documentation or scenes automatically. All consumer adoption remains manual. Do not ship a development steam_appid.txt or invent a production AppID when later distribution work is authorized.
